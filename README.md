# Telegram Translator Bot

Telegram-бот, который автоматически переводит сообщения выбранного чата на
несколько языков. Переводы отправляются ответом на исходное сообщение, а при
редактировании оригинала бот обновляет уже созданные переводы.

## Возможности

- автоматическое определение языка исходного сообщения;
- перевод на несколько языков через DeepL;
- автоматическое переподключение при разрыве DeepL-сессии;
- работа только в разрешённом Telegram-чате;
- обновление перевода после редактирования исходного сообщения;
- защита от повторной обработки одного сообщения;
- разбиение длинных переводов с учётом лимитов Telegram;
- перевод только обычного текста с заменой фрагментов кода на `[CODE]`;
- удаление внутренних emoji перед переводом с сохранением emoji в начале и
  конце сообщения;
- игнорирование сообщений, состоящих только из одной ссылки;
- хранение связей между исходными сообщениями и переводами в SQLite;
- поддержка обычных чатов и тем Telegram.

## Требования

- Python 3.10 или новее;
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).

## Установка

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/USERNAME/telegram-translator.git
cd telegram-translator
```

Создайте виртуальное окружение.

### Windows PowerShell

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Linux и macOS

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Настройка

Скопируйте пример конфигурации:

### Windows PowerShell

```powershell
Copy-Item .env.example .env
```

### Linux и macOS

```bash
cp .env.example .env
```

Откройте `.env` и заполните значения:

```dotenv
TELEGRAM_BOT_TOKEN=токен_от_BotFather
ALLOWED_CHAT_ID=-1001234567890
DROP_PENDING_UPDATES=true
DB_PATH=translator.db
```

Переменные окружения:

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота. Обязательная переменная. | - |
| `ALLOWED_CHAT_ID` | ID единственного чата, сообщения которого переводит бот. | `0` - переводы выключены |
| `DROP_PENDING_UPDATES` | Удалять накопившиеся обновления при запуске. | `true` |
| `DB_PATH` | Путь к SQLite-базе. | `translator.db` |

### Как узнать ID чата

Бот может работать в одном из двух режимов:

- **В личной переписке.** Откройте диалог с ботом и отправляйте сообщения
  непосредственно ему. Бот будет переводить сообщения из этого диалога.
- **В группе или супергруппе.** Добавьте бота в группу, и он будет переводить
  сообщения участников внутри неё. Чтобы бот получал обычные сообщения группы,
  отключите для него Privacy Mode через команду `/setprivacy` у
  [@BotFather](https://t.me/BotFather).

В `ALLOWED_CHAT_ID` указывается ID выбранного места работы: либо личного диалога,
либо группы. Одновременно бот обрабатывает только этот один чат.

1. Укажите токен в `.env`, а `ALLOWED_CHAT_ID` временно оставьте равным `0`.
2. Запустите бота.
3. Откройте личный диалог с ботом или добавьте его в нужную группу - в
   зависимости от выбранного режима.
4. Отправьте команду `/chatid` именно в этом личном диалоге или группе.
5. Скопируйте полученный ID в `ALLOWED_CHAT_ID` и перезапустите бота.

Для группы или супергруппы ID обычно является отрицательным числом.

## Запуск

При активированном виртуальном окружении выполните:

```bash
python bot.py
```

После успешного запуска в журнале появятся имя бота и разрешённый ID чата.
Для остановки нажмите `Ctrl+C`.

## Добавление и редактирование языков

Все целевые языки находятся в одном месте -
[`app/languages.py`](app/languages.py):

```python
TARGET_LANGUAGES = {
    "ru": ("🇷🇺", "Русский"),
    "en": ("🇬🇧", "English"),
    "cs": ("🇨🇿", "Čeština"),
}
```

Формат каждой записи:

```python
"код_языка": ("флаг", "название")
```

Например, чтобы добавить немецкий язык:

```python
TARGET_LANGUAGES = {
    "ru": ("🇷🇺", "Русский"),
    "en": ("🇬🇧", "English"),
    "cs": ("🇨🇿", "Čeština"),
    "de": ("🇩🇪", "Deutsch"),
}
```

Больше ничего менять не требуется: сервис перевода и форматирование сообщений
используют этот словарь автоматически. Порядок записей в словаре определяет
порядок переводов в ответе бота. Код должен поддерживаться DeepL.

## База данных

SQLite-база создаётся автоматически при первом запуске. Она хранит только
связи, необходимые для защиты от дубликатов и обновления переводов.

## Важное замечание

Проект использует неофициальный клиент бесплатного DeepL. Его работа зависит
от доступности внешнего сервиса и может измениться без предупреждения.
